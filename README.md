# R3ELio v1 • Firebase Login

Questa versione aggiunge una schermata di login reale con Firebase Authentication e autorizza nell'interfaccia un solo UID. Il contenuto multimediale rimane nel database locale dell'iPhone (IndexedDB); non viene caricato in Firebase.

**LEGGI PRIMA:** `GUIDA-FIREBASE.md` per configurare Firebase, impostare `firebase-config.js`, pubblicare con GitHub Pages e capire i limiti di sicurezza.

Funzioni dell'archivio e montaggio base come nella v1 precedente. L'AI visiva avanzata, la ricerca conversazionale vera e l'export MP4 garantito non sono ancora disponibili.
